15 уравнений: от простейших до особых случаев.
Ответ — число (отрицательное пиши с минусом: −3).
Решения откроются только после всех заданий.

Алгоритм решения линейного уравнения:
  1. Есть скобки — раскрой их (каждое слагаемое умножь на число перед скобкой; минус перед скобкой меняет все знаки).
  2. Есть дроби — умножь каждое слагаемое обеих частей на общий знаменатель.
  3. Перенос: слагаемые с x — влево, числа — вправо, знак меняем!
  4. Подобные: сложи коэффициенты при x.
  5. ax = b → x = b : a. Делим на a вместе со знаком! И сделай проверку подстановкой.
Особые случаи: 0 = 0 → корней бесконечно много · 0 = 5 → корней нет.
